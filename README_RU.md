# Talend Job Tools для IntelliJ IDEA

[English version](README.md)

Редактируйте Jobs из **Talend Studio 8** в **IntelliJ IDEA 2026.3** (сборка 263.7307 или новее в ветке 263). Плагин правит исходники Talend, а не сгенерированный Java-код.

## Сборка и установка

Скачайте ZIP из [GitHub Releases](https://github.com/atrevido/idea-talend-job-tools/releases) или соберите его из корня репозитория. Для сборки нужны JDK 25 и IDEA 2026.3 с плагинами Java и XML. На macOS можно использовать JBR из IDEA:

```sh
export IDEA_HOME="$HOME/Applications/IntelliJ IDEA.app"
export JAVA_HOME="$IDEA_HOME/Contents/jbr/Contents/Home"
./gradlew check buildPlugin
```

В IDEA: **Settings → Plugins → ⚙ → Install Plugin from Disk**. Выберите скачанный ZIP или `build/distributions/talend-idea-plugin-<версия>.zip`.

## Работа с проектом Talend

1. Откройте каталог с `talend.project` или его непосредственный родитель. Укажите в настройках IDEA тот же Project SDK, который используется для Jobs.
2. Двойным кликом в окне **Talend** можно открыть Job, Routine или Repository Context. Для статического `tRunJob` плагин открывает указанную версию или последнюю, если версия не задана и цель однозначна. После изменения структуры проекта нажмите **Refresh**.
3. В `.item` выберите **Tools → Edit Talend Java…** или одноимённый пункт контекстного меню. Фрагмент откроется в обычной вкладке IDEA с Java-подсказками, навигацией и форматированием.
4. Нажмите **Apply to Job**, затем **Save All**. Закрытие последней вкладки без применения отбрасывает черновик. Плагин меняет только выбранный XML-атрибут и отклоняет запись, если Job изменился или в файле смешаны типы переносов строк. Не редактируйте тот же Job одновременно в Studio: она может перезаписать правку своей старой копией.

Поддерживаются `tJava`, `tJavaRow` и существующие выражения и фильтры стандартного `tMap`, в том числе пустые. Подсказки используют поля контекста, схемы строк и Routines текущего репозитория Talend. Для внешних классов настройте зависимости в IDEA. Поле `IMPORT` редактируется как текст, чтобы IDEA не удалила импорты, используемые в другом XML-атрибуте.

Фрагменты не являются самостоятельными Java-классами. Рефакторинги, требующие изменить сгенерированные классы или схемы, не поддерживаются. Плагин не меняет граф, не генерирует, не компилирует и не запускает Jobs.

## CI и релизы

Pull requests запускают тесты JUnit и сборку ZIP на закреплённой версии SDK IDEA. ZIP и отчёты при падении тестов доступны в артефактах Actions. Тесты используют синтетические Jobs; отдельный проект Talend не нужен.

Чтобы выпустить релиз, обновите `version.txt` и влейте изменение в `main`. Workflow **Release** запускает те же проверки и публикует GitHub Release `v<версия>` с проверенным ZIP, `SHA256SUMS` и `BUILD_INFO.txt`. Пуши с уже выпущенной версией проходят проверки, но не меняют релиз. Если запуск завершился ошибкой, перезапустите его: публикацию черновика можно продолжить только с того же коммита. Gradle берёт из `version.txt` версию дескриптора и архива.
